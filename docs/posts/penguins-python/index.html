Penguin body mass in Python

Author

Taishi Huang

Published

September 23, 2026

Gentoo penguins are heavier than the other two species in the Palmer Penguins data. This post checks that with pandas and a box plot.

Data: Palmer Penguins, Palmer Station Antarctica LTER. Licence: CC0.

from palmerpenguins import load_penguins
import pandas as pd
import altair as alt
penguins = load_penguins()
penguins.shape
(344, 8)
mass_by_species = (
    penguins.groupby("species", as_index=False)["body_mass_g"]
    .mean()
    .round(1)
)
mass_by_species
species body_mass_g
0 Adelie 3700.7
1 Chinstrap 3733.1
2 Gentoo 5076.0

The table is the mean body mass in grams. Gentoo is the heavy species.

alt.Chart(penguins.dropna(subset=["body_mass_g"])).mark_boxplot().encode(
    x=alt.X("species:N", title="Species"),
    y=alt.Y("body_mass_g:Q", title="Body mass (g)"),
).properties(width=520, height=320)

The boxes do not overlap much. Gentoo sits well above Adelie and Chinstrap, which are close to each other.
